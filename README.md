# OnTrack

A personal task and deadline tracker for desktop and Android browsers.

This public repository contains synthetic demo tasks and placeholder connection settings. It contains no personal task data or production credentials.

## Development

Requires Node.js 22.13 or later.

```sh
npm ci
npm run dev
```

Open the loopback address printed by the development server. Production Sheet access requires a separately configured Google Apps Script connection.

Features are added in separate commits: data integration, task workflows, recurring tasks, calendar and analytics, appearance preferences, and activity history.
